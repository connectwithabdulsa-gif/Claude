# Message library

All copy for DFY GTM Systems outreach. CLAUDE.md rules apply: normal sentence case (never all lowercase), capitalize names, no em dashes, no banned words, one ask, every fact from a real stored field. Treat these as patterns to write from, not text to paste. Rotate variants so sends do not look identical.

Variables: `{{first_name}}`, `{{company}}`, `{{role_title}}`, `{{tool}}`, `{{show}}`, `{{place}}`, `{{round}}`, `{{timeframe}}`, `{{niche_plural}}`. Only fill a variable from a real data field. If a field is empty, use the plain fallback email.

## 1. Anatomy of email 1 (four short parts)

1. **Why you, why now.** What we saw, as a plain statement. One sentence.
2. **Why it matters to them.** One short sentence, no hype.
3. **Who i am and what i do.** One or two sentences in plain words.
4. **One ask.** A question they can answer with one word.

50 to 90 words total. No links. Sign off with "abdul".

Footer on every email:
```
abdul
dfy gtm systems
[ADD PHYSICAL ADDRESS]
not for you? just say so and i'll stop.
```

**Interested or "tell me more"**
```

easiest is 15 minutes where i map it out for you live. here's my calendar: https://calendly.com/connectwith-abdulsa/new-meeting

```

**"How much?"**
```
it's $2,000 a month flat for the whole setup and running it. the infrastructure (domains, mailboxes, tools) is billed at cost on top. happy to go through exactly what you'd get on a call.
```

**"Send me info"**
```
yep. here's the one page map for {{company}}: [link]. if it looks right, we can adjust it on a 15 minute call.
```

**"Not now"**
```
all good. i'll check back in {{month}}. anything in particular that would make it a better time?
```

**"We have an agency or do it in house"**
```
makes sense. if it helps, i can look at what you run now and tell you honestly if anything's missing. if it's covered, no pitch.
```

**"Is this automated?" or "is this AI?"**
```
yes. the research and sending run on a system i built. it's the same thing i'd build for you. any reply comes straight to me.
```

**"Too expensive"**
```
fair. what budget feels right? i'd rather cut scope (one niche, lower volume) than cut the price.
```

**Wrong person**
```
thanks for letting me know. who's the right person for outbound or growth at {{company}}?
```

**Unsubscribe or "remove me"** (automatic, then confirm)
```
done, you're removed. sorry about that.
```
